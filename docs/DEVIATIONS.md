# 与原版（chat-demo）的差异审计

本项目目标是「内容层 1:1 还原 + 外壳层 Liquid Glass 重构」。任何有意的差异都必须记录在此，避免后续被误判为 bug。

## 1. 刻意的设计差异

| 项 | 原版 | 本项目 | 原因 |
|---|---|---|---|
| 侧栏背景 | 实色 `#F9FAFB` / `#1B1B1C` | macOS 原生侧栏材质（模糊后方）+ 半透明同色叠加；iOS 为实色 | A1 决策：外壳层玻璃化，同时保证长文阅读可读性 |
| 输入框容器 | 实色 + 1px 边框 + 阴影 | 玻璃圆角 24pt + 同色描边 | 同上 |
| 设置弹窗 | 实色 Modal | 玻璃 sheet | 同上 |
| 折叠态展开按钮 | 普通图标按钮 | 玻璃圆角按钮 | 同上 |
| 窗口 | 浏览器无窗口概念 | macOS 透明窗口 + 自绘顶栏 + 红绿灯留白 66pt | 让玻璃能真实采样后方内容 |
| 窗口标题栏 | 浏览器无此概念 | macOS `.hiddenTitleBar` + 自绘顶栏 | 原生窗口规范 |
| 滚动条 | 自定义细滚动条 | 系统 overlay 滚动条 | 平台一致性 |

## 2. 技术实现差异（行为等价）

| 项 | 原版 | 本项目 | 影响 |
|---|---|---|---|
| 持久化 | IndexedDB（idb） | Application Support 下 JSON 快照（防抖写盘） | 无用户可见差异；不支持多标签页并发 |
| 语音输入 | MediaRecorder + 服务端转写 | 暂未实现（P2） | 功能缺失，已记入路线图 |
| 朗读 | Web TTS 音色（stella/tide） | 暂未实现（P2，计划 AVSpeechSynthesizer） | 功能缺失 |
| 附件 | Files API 上传 | 暂未实现（P1） | 功能缺失，输入框已预留按钮位 |
| 分支/版本切换 | BranchSwitcher | 已实现（`‹ 2/3 ›` 切换、编辑后分叉） | — |
| Markdown | mdast + KaTeX + Mermaid + Prism | 原生渲染 + 公式/图表 Web 岛 | 见 §3 |
| 思考用时 | 「已思考（用时 N 秒）」 | 完成态显示「已思考」 | 协议不返回块级时间戳，无法精确计时 |
| 国际化 | 中/英 | 中/英，设置内实时切换 | 已对齐 |
| 位置设置 | 省/市选择 | 未实现 | 与服务端地域相关，P2 |

## 3. 渲染差异

- 公式：KaTeX 在 WKWebView 内渲染，字体与浏览器一致；若本地资源缺失则降级为等宽源码。
- Mermaid：渲染为位图缓存，缩放时清晰度略低于矢量。
- 代码高亮：自研轻量着色器（关键词/字符串/注释/数字），不等同 Prism 的全语法树着色。
- 流式渲染：正文在流式期间持续重新解析（MarkdownDocumentCache 缓存最近 8 段），
  复杂度为 O(文本长度)；若后续出现长回答掉帧，改为「按 content_block_stop 才解析」。
- 思考用时：协议不返回块级时间戳，改用客户端计时（首个 text 块到达时间 − 消息创建时间）。
- 正文解析：`MarkdownView` 的异步解析路径在流式重渲染下会出现 document 未落地（正文空白），
  故 `AssistantBody` 采用同步解析 + 最近 8 段缓存（5KB 约 0.5ms）。修复后可切回。
- 行内代码：SwiftUI `Text` 无法对单个 run 做圆角与内边距，当前只有底色（上游 CSS 有圆角）。
- 公式：行内公式是图片、块级公式是 WebView，复制段落时公式不参与文本复制。
- iPad 顶部会出现系统窗口标题栏与状态栏（iPadOS 26 窗口化行为），非应用自绘。

## 4. 已知未对齐

- 历史导入导出（官方 zip 格式）未实现。
- 行内代码无圆角：SwiftUI `Text` 不支持对单个 run 做内边距。
- 网页来源的悬浮卡片（HoverCard）未实现，改为来源面板。
- iPad 顶部为系统窗口标题栏（iPadOS 26 窗口化行为）。

## 5. 不允许出现的差异

以下属于**必须一致**的内容，出现偏差按 bug 处理：
- 语义色值（背景、文本三级灰、品牌蓝、错误红）
- 正文字号 14px / 用户消息 16px / 行高
- 消息列最大宽度 840pt、横向 44pt、侧栏 261pt
- 控件高度 44/40/36/32/28 五档
- 会话分组规则（今天/昨天/7 天内/30 天内/按月）
- 思考时间线的标题文案
